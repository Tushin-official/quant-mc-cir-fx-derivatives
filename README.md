# Pricing Range Accrual на RUB/USD

Проект реализует симуляционную модель для оценки справедливой стоимости дериватива **Range Accrual** на валютную пару рубль/доллар.

В работе моделируются три связанных риск-фактора:

* мгновенная процентная ставка в рублях;
* мгновенная процентная ставка в долларах США;
* обменный курс RUB/USD.

Для процентных ставок используется модель **CIR** — стохастическая модель с возвратом к среднему, которая не допускает отрицательных ставок. Для валютного курса используется логарифмическая модель. Все риск-факторы симулируются совместно с учётом корреляций.

На основе полученных траекторий курса RUB/USD считается выплата по продукту **Range Accrual**. Идея продукта простая: чем больше дней курс находится внутри заданного диапазона, тем выше итоговая выплата. Если курс выходит за границы диапазона, выплата за такие дни не начисляется.

## Что реализовано

* симуляция процентных ставок RUB и USD;
* симуляция валютного курса RUB/USD;
* учёт корреляции между риск-факторами;
* Monte Carlo-моделирование большого числа сценариев;
* отдельный модуль для pricing Range Accrual;
* возможность задавать параметры продукта:

  * верхнюю границу диапазона;
  * нижнюю границу диапазона;
  * номинал сделки;
  * дату начала контракта;
  * дату окончания контракта.

## Как работает pricing

Модуль получает параметры продукта, запускает симуляцию рыночных факторов и анализирует траектории курса. Для каждой траектории считается доля времени, в течение которого курс находился внутри заданного диапазона. После этого рассчитывается средняя ожидаемая выплата по всем сценариям и приводится к справедливой стоимости продукта.

## Цель проекта

Цель проекта — показать, как можно использовать стохастическое моделирование и Monte Carlo-подход для оценки структурного финансового продукта, зависящего от поведения валютного курса во времени.
